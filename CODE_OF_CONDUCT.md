# Code of Conduct

steadypy has adopted the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in all project spaces, including issues,
pull requests and discussions, and when someone is representing the project
elsewhere.

In short, we pledge to make participation in this project a harassment-free
experience for everyone. Be respectful and constructive, assume good faith,
accept feedback gracefully, and focus on what is best for the community.
Harassment, insults, personal or political attacks, and publishing other
people's private information are not acceptable.

## Reporting

If you experience or witness unacceptable behavior, please contact the
project maintainer privately, using the contact details on the maintainer's
GitHub profile. All reports will be reviewed promptly and handled
confidentially.

The maintainer will follow the
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
of the Contributor Covenant, which range from a private correction to a
permanent ban, depending on the severity of the behavior.
